# Documentation index — Farmacia

Every document in this repo, and the facts it is the authority for. When two of them seem to state the same thing,
the one named here wins and the other should link to it.

| Document | Mode | Reader | It is the authority for |
|---|---|---|---|
| [`../README.md`](../README.md) | how-to + reference | developer, operator | What the app is, its status, how to stand it up and check it, the OCS contract's context, its licence |
| [`manual.md`](manual.md) | how-to, **in Spanish** | staff, and whoever administers the app | How to use each screen and the occ import, in the screens' own words |
| [`../CONTEXT.md`](../CONTEXT.md) | reference | everyone | **The vocabulary**: arsenal farmacológico, lente, planilla, lote, retirar/restaurar… |
| [`adr/`](adr/) | explanation | developer | Each decision, and the reasoning that was live when it was taken (0001–0004, no gaps) |

| [`../THIRD-PARTY-NOTICES.md`](../THIRD-PARTY-NOTICES.md) | reference | operator | The third-party components in the bundle and their licences |
| [`../CHANGELOG.md`](../CHANGELOG.md) | history | operator | What changed, per version |
| [`../openapi.json`](../openapi.json) | reference (generated) | other apps | The OCS contract. Generated by `make openapi` from the controller, never edited by hand |

The manual is Spanish because its reader is: it walks the screens, which are Spanish. Everything else here is
English, like the code.

Decisions that bind more than this app live in gestion, the trunk: own apps ship as vendored tarballs from
their own repositories
([gestion ADR-0003](https://github.com/APS-Conecta/gestion/blob/main/docs/adr/0003-this-stack-ships-a-custom-app.md)),
and the OCS surfaces every app publishes are listed in
[gestion `docs/CONTRACTS.md`](https://github.com/APS-Conecta/gestion/blob/main/docs/CONTRACTS.md).
